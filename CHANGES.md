## Review tooling (mockup only, NOT part of the theme work)
`site/mockup-changes.js` adds the orange **Show changes** button (bottom-right). It lists each change above, tags the changed elements on the current page with numbered orange labels and dashed outlines, and turns off completely with **Hide changes** (or Esc). The agency should ignore it; it is not to be reproduced in Shopify. To list a new change, add an entry to the `CHANGES` array at the top of that file.
